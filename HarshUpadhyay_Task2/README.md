# OIBSIP Data Science Internship - Task 2

# Unemployment Analysis in India

# The aim of this Task is to analyze unemployment data in India and understand how unemployment rates vary across different states and time periods.

The dataset contains information about:
* Unemployment Rate (%)
* Employment Statistics
* Labour Participation Rate (%)
* States/Regions
* Date-wise Records

# Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

# Project Workflow

1. Loaded the unemployment dataset.
2. Cleaned and prepared the data for analysis.
3. Performed Exploratory Data Analysis (EDA).
4. Created visualizations to identify trends and patterns.
5. Derived insights from the data.

# Key Insights

* Unemployment rates increased significantly during the COVID-19 period.
* Different states experienced different levels of unemployment.
* Employment and labour participation rates showed noticeable fluctuations over time.
