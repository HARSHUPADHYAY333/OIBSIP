# Unemployment Analysis in India

# Project Overview
The objective of this project is to analyze unemployment trends in India using real-world unemployment data. The analysis helps understand how unemployment rates vary across different states, regions, and time periods.

## Objective

The main objective of this project is to:
 Analyze unemployment data across India.
Identify trends and patterns in unemployment rates.
 Compare unemployment levels across different states and regions.
 Understand the impact of time and economic conditions on employment.


## Dataset
The dataset contains the following information:

| Feature | Description |
|----------|------------|
| Region | State/Region Name |
| Date | Date of Record |
| Frequency | Monthly Data Frequency |
| Estimated Unemployment Rate (%) | Unemployment Percentage |
| Estimated Employed | Number of Employed Individuals |
| Estimated Labour Participation Rate (%) | Labour Participation Percentage |
| Area | Urban or Rural Area |


# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

# Project Workflow

### 1. Data Loading
The unemployment dataset was loaded using Pandas.

### 2. Data Cleaning
Column names and date formats were cleaned and prepared for analysis.

### 3. Exploratory Data Analysis (EDA)
The dataset was explored to understand its structure and identify important trends.

### 4. Data Visualization
Several visualizations were created to compare unemployment rates, labour participation rates, and regional differences.

### 5. Insight Generation
Important observations and conclusions were derived from the analysis.

# Visualizations Performed

- Distribution of Unemployment Rate
- Top States by Average Unemployment Rate
- Urban vs Rural Unemployment Analysis
- Labour Participation Rate Distribution
- Correlation Heatmap


# Key Insight
- Unemployment rates varied significantly across different states.
- Some regions experienced much higher unemployment compared to others.
- Labour participation rates showed noticeable fluctuations across regions.
- Urban and rural areas displayed different unemployment patterns.
- The COVID-19 period showed a significant rise in unemployment rates.

# Results
The analysis successfully highlighted unemployment trends and regional differences across India. Data visualization helped in understanding employment patterns and identifying areas with higher unemployment rates.


# Conclusion
This project demonstrates how data analysis and visualization techniques can be used to study socio-economic indicators such as unemployment.
