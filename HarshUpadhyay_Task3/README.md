# Email Spam Detection

# Project Overview

This Task aims to build a Machine Learning model that can classify emails as Spam or Not Spam. The model is trained using email text data and Natural Language Processing (NLP) techniques.

##Tools and Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

# Machine Learning Algorithm

* TF-IDF Vectorization
* Multinomial Naive Bayes

# Project Steps

1. Load and clean the dataset.
2. Convert email text into numerical features using TF-IDF.
3. Split the dataset into training and testing sets.
4. Train the Naive Bayes model.
5. Evaluate the model using accuracy and confusion matrix.

# Results

The model successfully classified emails into Spam and Not Spam categories with high accuracy.

#Conclusion

This project demonstrates the use of Machine Learning and NLP techniques for email spam detection and classification.
